# Master Prompt

Mod cho Claude Code: thêm nút **✨ Master Prompt** ngay trên thanh nhập và lệnh `/mp`.
Gõ câu lệnh thô vào ô nhập, bấm nút (hoặc gõ `/mp`), mod gọi model viết lại câu lệnh cho rõ ràng,
đầy đủ, có cấu trúc rồi đặt lại vào ô nhập để bạn xem và sửa trước khi gửi.

Nút hiện trong app Claude (máy tính, iPad/điện thoại) và terminal; giao diện claude.ai trên trình duyệt không hiển thị mod.

## Cài đặt

Tại ô nhập của một phiên Claude Code trên máy tính:

```
/plugin install master-prompt --marketplace xbinh86/master-prompt
```

Hoặc từ cửa sổ dòng lệnh:

```bash
claude plugin install master-prompt --marketplace xbinh86/master-prompt
```

Trả lời `y` để thêm marketplace, rồi chọn phạm vi cài (user để dùng ở mọi dự án).
Repo đang để Private nên máy cài cần đăng nhập GitHub có quyền đọc repo này.
